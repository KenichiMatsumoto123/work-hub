# フロー運用設定

10フェーズ開発フローの、このリポジトリにおける運用設定。flow-phase 系 skill が実行時に参照する。

- 設定方法: flow-setup 導入時にユーザーへ確認（変更はこのファイルの直接編集で可）

## 人間承認ゲートの要否

| ゲート | 設定 | スキップ時の挙動 |
|---|---|---|
| Phase 3（設計書の人間承認） | {{必要 / 不要}} | 「不要」の場合、Phase 2（設計書レビュー・修正ループ）が Critical / Major 0 件で収束した時点で、司令塔が設計書ステータスを「合意済」に更新し（findings.md にスキップ記録を追記）、Phase 4 へ自動で進む |
| Phase 7（テストの人間承認） | {{必要 / 不要}} | 「不要」の場合、Phase 6（テストレビュー・修正ループ）が Critical / Major 0 件で収束した時点で、司令塔が findings.md に承認済み記録（スキップ記録）を追記し、Phase 8 へ自動で進む |

**注意：**

- 本ファイルが存在しない場合、flow-phase 系 skill は両ゲートとも「必要」として扱う（安全側デフォルト）
- 承認ゲートをスキップしても、レビュー・修正ループの収束条件（Critical / Major 0 件）は免除されない
- Phase 5 のテスト仕様確定フロー（影響度トリガー該当分の人間本記載・クリティカルパス E2E の人間承認）は本設定の対象外であり、スキップされない
