### 2.0 共通前提

1. ログイン済みが既定（`playwright.config.ts` の `storageState`）。
2. 各シナリオは他シナリオの実行結果・画面状態に依存しない。Given に「前シナリオの続き」を書かない。
3. **`waitForHydration`**：親 E2E `apps/web/e2e/effort-normalize.test.ts` と同型。`📝 日報` タブをクリックして `(1) 日報テキスト` が見えるまで `toPass({ timeout: 30000 })` し、`✏️ 入力` に戻す。日付入力やリンククリックの前に必ず行う。
4. **`waitForReportLoadSuccess`**：`page.getByTestId('report-load-status')` の要素数が 0（タイムアウト 10000ms）。日付欄 enabled 単独では待たない（AC-L63）。`goto('/')` のあとは hydration → 本待ちの順。
5. **ウォームアップ**：`beforeAll` で次の順だけ行う（保存しない）。親 `beforeAll` と同型だが保存クリックを省く。
   1. `goto('/')` → `waitForHydration` → `waitForReportLoadSuccess`
   2. 日付欄を `2000-04-09` にする（未保存なし）。成功完了を再度待つ
   3. 保存ボタンは押さない
   4. `afterAll` で `2000-04-09` だけを規定 8 どおり削除する
   コールドスタートをシナリオ本体の待ちに混ぜない。

### 2.2 今日日付の算出（E2E-L3 専用）

`page.evaluate` 内で次のスニペット**だけ**を使う（AC-L05 の `getToday` と同じ。`format()` の戻りをパースしない。`toISOString` を使わない）。

```ts
function expectedJstTodayYmd(): string {
  const parts = new Intl.DateTimeFormat('en-US', {
    timeZone: 'Asia/Tokyo',
    year: 'numeric',
    month: '2-digit',
    day: '2-digit',
  }).formatToParts(new Date())
  const year = parts.find((p) => p.type === 'year')!.value
  const month = parts.find((p) => p.type === 'month')!.value.padStart(2, '0')
  const day = parts.find((p) => p.type === 'day')!.value.padStart(2, '0')
  return `${year}-${month}-${day}`
}
```
