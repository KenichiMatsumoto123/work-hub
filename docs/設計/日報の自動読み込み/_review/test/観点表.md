- **1章**は結合(DB込み)の影響度トリガーが設計書どおりすべて非該当のため、チェックリスト行は「該当なし（理由）」が主。ただし設計書が **AC-L10 / AC-L11 を結合(DB込み)必須**としているので、その技術検証だけを起案する（モック SELECT はトートロジーになるため）。

### 2.0 共通前提

1. ログイン済みが既定（`playwright.config.ts` の `storageState`）。
2. 各シナリオは他シナリオの実行結果に依存しない。
3. 後始末は `report-db-helpers` 相当。自分が作った `2000-02-*` の行だけ削除する。TRUNCATE しない。
4. **読み込み成功完了待ち（AC-L63）**：`data-testid="report-load-status"` の要素が無いこと。日付欄 enabled 単独では待たない。
5. 画面上の一致の観測点は日付欄・始業・取引先名・実績h・良かった点の 5 つ（設計書共通前提）。
6. JST 0:00〜8:59 の境界は単体 AC-L01〜L03。E2E-L3 では Date を固定しない。
7. `beforeunload` は自動化しない。
