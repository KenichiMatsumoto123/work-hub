# 設計書作成ルール

- 各項目には【必須】または【任意】を付記している。【必須】項目は必ず記載すること。【任意】項目は該当する場合のみ記載する。
- この設計書に含まれない項目であっても、機能として必要な情報があれば随時セクションを追加すること。フォーマットに縛られず、その機能に最適な形で設計を記述してよい。
- 項目定義の対象は「DB連携がある項目」「バリデーションルールがある項目」「表示ロジックが複雑な項目」に限定する。静的テキスト（ラベル・説明文・タイトル類）はデザイン原本を正とし、項目定義に含めない。
